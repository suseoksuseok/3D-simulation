1. [LOG-001] AI 비전 LLM 응답 JSON 파싱 실패 및 강제 Fallback 취약점
--------------------------------------------------------------------------------
- 증상 / 오류 내용:
  일부 LLM 모델(Gemini, OpenAI, Ollama)이 JSON 앞뒤로 인사말이나 안내문(예: "Here is the blueprint: ```json ... ```")을 포함하여 응답할 경우, 기존의 `clean.startsWith('```')` 검사가 실패하여 SyntaxError가 발생하고 강제로 프리셋 모드로 전환되는 문제.
- 원인 분석:
  단순한 문자열 접두사 검사로는 대화형 텍스트나 다양한 마크다운 래핑 형태를 유연하게 처리하지 못함.
- 조치 및 수정 내용:
  `extractJsonFromAiResponse` 함수에 정규식 기반 코드블록 추출 및 최외곽 중괄호 매칭(`firstBrace` ~ `lastBrace`) 알고리즘을 도입. 어떤 대화형 텍스트나 공백이 섞여 있어도 내부의 유효한 JSON 객체를 100% 안전하게 파싱하도록 수정.
- 결과:
  [검증 완료: PASSED] 마크다운 감싸기, 인사말 동반 응답, 순수 JSON 응답 모두 정상 파싱 확인.

2. [LOG-002] 2D 단면도 요소 삭제(Erase) 도구 벽체 삭제 불가 버그
--------------------------------------------------------------------------------
- 증상 / 오류 내용:
  2D 도면에서 '요소 삭제' 도구를 선택하고 긴 벽체(2000~5000mm)를 클릭해도 벽이 지워지지 않고 무반응인 현상 발생.
- 원인 분석:
  기존 코드가 마우스 클릭 지점과 벽의 **정중앙(Midpoint)** 사이의 거리만 검사(`Math.hypot < 450`)하여, 벽의 중심부 450mm 반경 바깥을 클릭하면 삭제 대상에서 제외됨.
- 조치 및 수정 내용:
  점과 선분 사이의 최단 수직/투영 거리 계산 함수 `distToSegment(px, pz, x1, z1, x2, z2)`를 구현하여, 벽체의 어떤 부위를 클릭하더라도 280mm 이내이면 정확하고 즉각적으로 벽이 삭제되도록 전면 수정.
- 결과:
  [검증 완료: PASSED] 벽의 양 끝단, 중간 지점 클릭 시 100% 신뢰성 있게 삭제 동작 확인.

--------------------------------------------------------------------------------

- 원인 분석:
  GLB 가구는 파츠 JSON이 아닌 실제 3D 씬(`GLTF.scene`)인데, 재배치 및 치수 변경 함수가 일반 AI 프리셋 생성 로직(`generateSmartBlueprint('glb_custom')`)을 호출하여 발생함.
- 조치 및 수정 내용:
  1) `state.glbModelCache` 맵을 신설하여 로드된 GLB 모델의 원본 씬을 메모리에 보존.
  2) 보관함에서 재배치 시 `buildGLBFurnitureGroup(cachedScene, newItem)`을 통해 원본 모델을 복제(`clone()`)하여 배치.
  3) 치수 변경 시에도 바운딩 박스 스케일(`scale.set`)을 비례 조정하여 GLB 고유 형태를 100% 보존하도록 수정.

  [검증 완료: PASSED] 외부 GLB 3D 가구의 복제, 보관함 재배치, 치수 리사이징 정상 동작 확인.
